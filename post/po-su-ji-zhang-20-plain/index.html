朴素记账 2.0 - Plain 1.0

2026-04-03 2 分钟阅读

Plain

它源自一个简单的理念——朴素记账法：记账不应成为负担，而应是让生活更轻松、更有智慧的工具。
Plain 诞生钱，我坚持用 Excel 的预算表，保持着“朴素的”核心理念。

最近 Vibecoding 的自动化实验，最终形成的一套易用、可持续的个人记账系统。

从 Excel 到 Vibecoding，再到 Plain

  1. Excel 时代

    • 用 Excel 制作收入-支出-存储的预算模板，一眼就看明白哪些是固定开支，哪些是弹性消费。
    • 简单、透明，但缺少互动性与自动化。

  2. Vibecoding 实验

    • 为了让记账更有仪式感和自动化体验，尝试用 Vibecoding 构建记账流程：
      • 每天的数据自动计算
      • 预算提示
      • 弹性额度管理
    • 让枯燥的数据变得“活”起来。

  3. Plain 诞生

    • 将理念落地为 App：低摩擦、轻量化、情绪化交互
    • 无需手动计算、无需翻看复杂报表，每天只需轻轻一点，就能掌握财务状态。

Plain 的核心哲学

  • 记账是为了决策，而不是审计
    关注“我今天/本月还能花多少”，而不是每一笔分类是否精确。

  • 接受生活的不确定性
    银行余额与账本不一致没关系，Plain 提供一键对账功能，让数据回归现实。

  • 低摩擦体验
    记账动作越简单越可持续，超过 3 秒的复杂操作会让习惯难以坚持。

  • 生活体验优先
    弹性预算保护体验消费，让储蓄和生活满足感共存。

核心特色

  1. 自由账期管理

    • 可按工资日或个人习惯自定义账期
    • “本周期余额”永远清晰可见

  2. 对账优先、分类淡化

    • 账本余额 vs 实际余额一目了然
    • 一键校准差额，减轻焦虑

  3. 高效录入

    • OCR 识别小票文字及布局
    • 集成 iOS 快捷方式，支持 Siri 或动作键快速记账

  4. 情绪化 UI

    • 网格渐变 + 超薄玻璃材质
    • 每笔交易像精心设计的卡片，让理财充满质感

  5. 弹性预算机制

    • 日常基础支出有目标控制
    • 偶尔兴趣消费有弹性额度保护，避免负反馈循环

Plain 的愿景

Plain 不想成为你手机里的“理财专家”，它想成为你 生活中的小伙伴：

  • 安静、优雅，懂你日常的财务节奏
  • 提供透明、可控的预算视野
  • 用最朴素的方式，让生活更轻松、更有智慧

写在最后

Plain 是 Excel 脱胎的智慧，是 Vibecoding 的实验结果，更是一种生活态度：

朴素而有计划，简单却不失智慧。

在 Plain 里，你不只是记账，你是在用简单工具管理生活、优化体验、积累智慧。

Plain = 朴素 + Plan
简单的生活，清晰的计划，智慧的选择。

朴素记账 2.0 Plain！
